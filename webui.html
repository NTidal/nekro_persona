毛玻璃不透明度自动

              
            

            

              
毛玻璃模糊度自动

              
            

            

              
              
            

          

          

            选中即生效：图片会等比铺满 + 按目标尺寸裁剪 + 模糊，再自动做明暗补偿保证文字可读
            （明暗补偿 0 = 自动，负数压暗、正数提亮）。照片较花时可调低模糊或加大补偿。
              
毛玻璃不透明度：卡片上那块磨砂面板的浓度。0 = 全透（只剩模糊，背景花纹直接透出来），
              100 = 几乎不透（最干净但看不到背景）；拖到最左「自动」= 各面板按预设浓度，图片背景自动加厚一点。
              毛玻璃模糊度：面板背后那层磨砂的模糊半径，0 = 面板里是清晰底图（只剩白纱），越大越糊。
              
作用范围：先选「只单人卡 / 只排行榜 / 只印象总览」，再选或上传图片，就只改那张卡的背景；
              选「全部卡片」相当于以前的通用背景（其它卡没单独设图时也跟随它）。
              
裁剪锚点：只影响被裁掉的那个方向。自动 = 在 64×64 缩略图上算边缘能量找主体（人脸/轮廓），
              再与画面中心混合一半、夹在 15%~85%，避免为几根树枝把构图裁飞；主体偏上时选「顶部对齐」或「偏上一点」。
              
文字配色：自动会先估算面板最终亮度（背景亮度与该层白纱按毛玻璃浓度混合），
              偏暗就整套换成浅色墨（含强调色/标签底），偏亮就用原来的深色墨 —— 深色背景或把毛玻璃调到很透时不会再糊成一片。
          

        

      


        

          

            

              
外观配色（DIY）

              
只改颜色，卡片框架（尺寸/间距/结构）固定

            

            默认
          

          

            

            

              
              
            

            

              每行一个颜色：取色器与十六进制框互通（六位色值不写 #也会自动补上），点「默认」只重置这一项。

              拖动取色器时只更新色块（那行会亮个边），松手才保存并重渲——拖一圈也只渲一次。

              输入 #0 = 不渲染该块：正文/次级/弱化 → 那几行字不画；
              强调色 → 进度条与标签内的字不画；标签底 → 只留标签文字；毛玻璃面板底色 → 面板整块去掉；背景薄纱色 → 不蒙薄纱。
              （内置渐变三色不支持 #0，因为它们没有"不渲染"的语义。）
              这里只动颜色（正文/强调/标签底/毛玻璃底色/背景薄纱/内置渐变三色），
              位置、尺寸、层次这些框架参数不开放修改。

              阶段徽章（常客 / 亲近 / 特别亲密…）与排行榜名次的金银铜属于语义色，不随这里变化。
